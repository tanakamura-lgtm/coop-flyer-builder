# コープさっぽろ チラシ作成アプリ（Coop Flyer Builder）

添付のコープさっぽろ「号外！」チラシ（8コマ構成・ポイント10倍）を忠実に再現し、商品の追加・変更・価格・画像の編集を自由に行えるWebアプリケーションです。

---

## 🌟 主な特徴

1. **上段デザインの引用（忠実再現）**:
   - 添付PDFから切り出した「COOP SAPPORO つなぐ ロゴ」「特大『号外！』ロゴ」「土日ちょこっとカードなら11倍・その他10倍ポイント告知」を高精細に引用。
   - カレンダーから売出し日付を選ぶと、チラシヘッダーの「9月6日(日)」などの月・日・曜日が自動更新されます。

2. **8コマ商品エディタ**:
   - 2列×4行の8コマ構成。
   - 商品名、産地・メーカー名、内容量・規格、キャッチコピー、バッジ（数量限定、お1人様2点限りなど）を自由に編集可能。
   - 各コマをクリックするか、上部の「コマ1〜8」セレクターで直感的に切り替え。

3. **消費税8％の自動反映**:
   - 本体価格（税抜）を入力すると、日本のスーパーマーケット標準計算（$本体価格 \times 1.08$ 四捨五入）により税込価格がリアルタイムに自動反映されます。
   - 添付チラシの「96円 → 税込104円」「379円 → 税込409円」「999円 → 税込1,079円」などに100%合致。必要に応じて手動での微調整も可能です。

4. **WEBからの画像検索 & 高画質プリセット**:
   - 商品名を入力して「🔍 WEB画像検索」を押すと、フリーの画像API（Wikimedia Commons）から候補写真が一覧表示され、ワンクリックで設定可能！
   - 玉ねぎ、シャウエッセン、紅鮭、まぐろ、鶏肉、みかん、ぶどう、お米、油、お茶など、コープさっぽろ定番のプリセット写真も内蔵。
   - お手元のパソコンの写真（ドラッグ＆ドロップ）や画像URLの指定にも対応。
   - 画像の拡大縮小（Zoom）や上下位置の微調整スライダー付き。

5. **下段対象店舗の4店舗限定掲載**:
   - ご指定の4店舗（**パセオ堺町店・えりも店・東町店・様似店**）のみを青いグラデーション枠で綺麗にレイアウト。
   - 営業時間や電話番号の変更も可能です。

6. **印刷 & 高解像度画像保存**:
   - **A4印刷 / PDF保存**: ブラウザの印刷ダイアログ（Ctrl+P）でA4用紙にフチなしでぴったり収まる専用プリントレイアウト。
   - **画像保存 (PNG)**: ワンクリックで高解像度PNG画像としてダウンロード。
   - **データ保存 / 読込**: JSON形式でのバックアップ・再読込、およびブラウザへの自動保存に対応。
